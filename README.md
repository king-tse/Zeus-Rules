## 🛠 分流配置教学
以下提供主流代理工具的「分流规则」配置方法，只需将需要的的流量规则链接引导至需要的的节点即可。

### 🚀 Shadowrocket

1、打开 Shadowrocket。

2、点击 配置 → 点击您正在使用的配置文件后方的 i → 规则 → 右上角 + 号新增。

3、类型：选择 RULE-SET

4、策略：选择 PROXY 或您专门为该规则建立的策略组或者地区节点。

5、规则集 URL 填写以上需要的链接：

6、点击右上角「保存」并确保套用配置。
